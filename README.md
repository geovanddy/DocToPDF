# 📄 DocToPDF

App Android para convertir archivos **Word, Excel y PowerPoint a PDF** y abrirlos directamente en **Google Drive** — sin publicidad, sin esperas.

## ✅ Formatos soportados
- 📝 Word: `.doc` / `.docx`
- 📊 Excel: `.xls` / `.xlsx`
- 📑 PowerPoint: `.ppt` / `.pptx`

## 🚀 Cómo compilar la APK en GitHub

### Paso 1 — Subir el proyecto
1. Ve a [github.com](https://github.com) e inicia sesión
2. Crea un nuevo repositorio llamado `DocToPDF`
3. Sube todos los archivos de este proyecto

### Paso 2 — Ejecutar la compilación
1. Ve a la pestaña **Actions** de tu repositorio
2. Verás el workflow **"Build APK"**
3. Si no inició automáticamente, haz clic en **"Run workflow"**
4. Espera ~5-8 minutos

### Paso 3 — Descargar la APK
1. Cuando termine (✅ verde), haz clic en el workflow
2. Baja hasta **Artifacts**
3. Descarga **DocToPDF-debug**
4. Descomprime y transfiere el `.apk` a tu celular
5. Instala (necesitas permitir "instalar apps de fuentes desconocidas")

## 📱 Cómo usar la app
1. **Desde la app:** toca "Seleccionar archivo" y elige tu Word/Excel/PPT
2. **Desde el explorador:** abre cualquier archivo Office y elige "DocToPDF" como app
3. La conversión es instantánea y el PDF se abre en Google Drive automáticamente

## 🔒 Privacidad
- Todo se procesa **localmente en tu dispositivo**
- No envía datos a ningún servidor
- No requiere internet para convertir
